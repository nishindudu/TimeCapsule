# TimeCapsule

A website for creating time capsules.

## Setup

1. Clone the repo

2. Install dependencies
    ```bash
    py -m pip install -r requirements.txt
    ```

3. Set ```DATABASE_URL``` and ```TOKEN``` environment variables.

3. Run the app
    ```bash
    waitress-serve --host=0.0.0.0 --port=80 main:app
    ```
